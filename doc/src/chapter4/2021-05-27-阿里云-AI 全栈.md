# 二、 面试回顾

## 2.1 面试题目


这次面试中面试官提出的问题如下：

1. 你觉得你自己的这个做的哪个项目最难？它的难点在哪？
2. 那你是怎么解这个问题呢？就是这个问题，这个问题是你解决的还是这个不是你解决的。
3. 这个分布式改造，然后是你自己在做的，还是说你其实是那个，你是其中一个参与者，还有其他人共同参与。
4. 所以你主要做哪一块？
5. 你对网络的通讯协议什么的你有了解吗？
6. 那你能给我讲一下那个 e pool，然后和 b pool 的这个区别吗？
7. 那你就讲讲 e pool 好了。
8. c 加加你的这个用的多吗？
9. ok，那个 c 加加上面的这些开发，你大概写了多少啊？就是你现在是一直是这个在一线的，是吧？
10. 那你这个正确不出错，这个事情你是如何来保证的呢？
11. 你数据结构你学过吗？
12. 如果要去实现一个这个数的广度优先遍历，要怎么做？
13. 如果要给你一个列表，让你去做一个反转，然后它的设计思路应该是怎么样的？
14. 如果给你一堆的数据，然后让你以最快的速度去找到里面次大的数，然后你怎么去做？
15. 如果是那个让你算前 k 大的数，嗯？
16. 你这个复杂度有多高？
17. 那如果 n log n 的话，然后你就可以把整个这个排完了？
18. 那假如说如果是堆排序，它的时间复杂度有多少？
19. 建大顶堆的时间复杂度是多高？
20. 大顶堆里面要去找到最小的那个数，应该怎么办？
21. 然后，哎，你前面说是什么方法？是什么？除了挨个 pop 之外，前面是什么？
22. 你是问我我们都那个怎么去解决这些挑战，是吧？
