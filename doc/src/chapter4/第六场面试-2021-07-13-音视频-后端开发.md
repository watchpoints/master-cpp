## 2.1 面试题目


飞书 Docs Link: 
https://wnso49yyot.feishu.cn/docx/IUaPdslFPouZDFxnGtqcxZqlnvg Password: 52a#2147

1. 您先介绍一下你现在那个做的一些项目。
    
2. 咱一个一个项目，一个项目问，就是我看那个项目有涉及到一些第二个项目，第三个我有涉及，我看你那边有一些什么优化，提高编译效率等等这些。
    
3. 为什么这些流媒体协议，我看你尝试升级 UDP 传输，像底层都是用 UDP 来传输，是吗？
    
4. 为什么像这种流媒体的都会尝试用 UDP？但我们实际上很多 RPC 各个地方通信其实是 TCP 为主。
    
5. 你了解到如果像这种视频媒体，如果有包丢了，或者有数据包传错了，在上层有什么方法来做处理吗？
    
6. TCP 的话都说是它是可靠的，低于 UDP，那可靠是怎么来保障这个可靠？有哪些手段来保证 TCP 传输的可靠？
    
7. 你说的这个快速重试怎么判断呢？什么情况下？
    
8. 这个20、30是代表什么？
    
9. sequence number 是怎么来定的？它有什么意义？
    
10. 你们那个说是线程模型，是用的 epoll 加协程，是吗？处理是在协程里？
    
11. 这个携程是用的库还是你们公司内部自研的还是什么？
    
12. 它大致流程是什么样？这大致的架构？
    
13. 这种 event Loop 有遇到过什么问题吗？这种在一个单线程里跑 event loop？
    
14. 这种怎么解决呢？或者你们的场景有遇到这样的情况吗？
    
15. 你有没有遇到过负载不均的问题？或者说你了解他内部是怎么来做这个负载均衡的吗？
    
16. 你使用过别的框架或者说有了解过这方面吗？能够能高效的利用多核的？
    
17. 假设有这样的话，要你设计一个分这个 event 跟 worker 线程，分那个 IO 线程跟 worker 线程，你觉得需要注意哪些问题啊？假设要你实现这么一个库，你可以想一下，大致你觉得会碰到什么问题？怎么解决？
    
18. 说到这个水平触发，边缘触发，你要是用异步的话，到底是选边缘还是选水平？这个怎么考虑的？
    
19. 比如像 Redis 用的是边缘还是水平触发？
    
20. 你这个携程的话，了解过哪些携程的实现吗？或者是不管是开源的或者是用过吗？你们这个库，这个携程是你们用的这个库自己封装的一套，是吗？
    
21. go 的携程了解吗？
    
22. Redis 你们用的比较多是吗？
    
23. 有用过比如说主从的或者是集群模式，主从模式这种吗？
    
24. 这个 proto buffer 的，你们这个数据交互是用 proto buffer？
    
25. 你们这个开发平时都是用 c 加加，是吗？
    
26. c 加加那个 map 跟 unordered_map 有什么区别？
    
27. 那我要是有一个 KV 场景你怎么选呢？
    
28. 常用的哈希的算法，或者是哈希的常用的有了解吗？
    
29. 对于大部分是有序、少量位置无序（偏差不超过k，k远小于n）的序列，用哪种排序算法会比较快？
    
30. c 加中的引用跟指针一般你这边怎么用啊？或者有自己什么自己的想法，或者使用场景方面，比如说什么时候用引用，什么时候用指针，或者它俩的区别？
    
31. 假设我们一个函数，我为了避免那个深拷贝，是吧？我把它写成这个某个参数的引用还是某个参数的指针，这有什么不一样吗？
    
32. 你对那个设计模式有什么理解吗？或者常用的设计模式，或者设计模式主要关注的一些点？
    
33. 虚表的指针存在什么地方？
    
34. Linux 的代码写好了之后，一个可执行文件加载进去之后，它的内存大致分为哪几块？
    
35. 虚函数的指针什么时候赋值的？初始化的？
    
36. 构造函数中的哪个地方初始化虚函数指针？是在构造列表中还是构造函数体中，是在函数体的前面？
    
37. 在构造函数中能调用虚函数吗？
    
38. 虚函数指针是在什么时候初始化比较合适？
    
39. 初始化列表里可以调用虚函数吗？
